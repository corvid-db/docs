Your first database

This tutorial walks through opening a database, storing documents, and reading them back. Examples are Rust (the engine’s native language); the same shapes exist through the C ABI and bindings as native classes.

Open a database

Section titled “Open a database”

A Db is one embedded database file. Open it once and share it — it is Send + Sync; wrap it in Arc to share across threads. A second Db handle to the same file fails on the storage engine’s exclusive lock, so one process, one handle, is the pattern.

Collections and documents

Section titled “Collections and documents”

A collection is a named namespace of documents, created lazily on first write. A document is a typed Value — usually a map. A key is arbitrary bytes; documents sort by key.

Names starting with __ are reserved for the engine and rejected; names may not contain a NUL byte or an interior __ sequence.

Write modes

Section titled “Write modes”
MethodUse
insert(key, &doc)insert / full overwrite
insert_batch(&[(&[u8], &Value)])many docs in one transaction (one fsync)
insert_auto(&doc) -> Vec<u8>append under a generated ordered key
patch(key, &partial_map)merge top-level fields into an existing doc
update(key, |cur| -> Option<Value>)read-modify-write (return None to delete)
compare_and_set(key, expected, new)atomic conditional write / delete / insert-if-absent
delete_where(predicate)delete every matching doc (index-accelerated)
delete_batch(&[&[u8]])delete a set of keys

See writes for the full semantics of each mode.
